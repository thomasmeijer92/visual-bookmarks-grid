# Visual Bookmarks Grid Agent Notes

This branch is a public starter template. Keep it free of personal bookmark data, local file paths, account identifiers, private screenshots, API keys, cookies, and generated media exports.

## Public Starter Rules

- Use English for UI, docs, commit messages, PR copy, and extension copy.
- Keep sample data generic and local. Use `example.com` or local assets for sample links.
- Do not commit `bookmarks-data.json`, `media-cards-clean.json`, `web-clips.json`, `manual-media-notes.json`, `assets/clips/`, logs, browser screenshots, `.env`, or `.env.local`.
- If a feature needs private data locally, document the file shape and keep the actual data ignored.
- Prefer small PR-sized branches with a clear story, checks, and review before merge.

## Validation

Run:

```bash
npm run check
```

For UI changes, also verify the local app at `http://127.0.0.1:3000` with the sample data.
